Projet d'analyse de données avec Excel

1. Présentation du projet

Ce projet consiste à utiliser Microsoft Excel pour organiser, traiter et analyser des données afin d'en tirer des informations utiles à la prise de décision.

2. Outil utilisé

- Microsoft Excel
- 
3. Travaux réalisés

- Organisation des données
- Nettoyage et préparation des données
- Analyse des données
- Utilisation de formules et de fonctions Excel
- Création de tableaux et de graphiques, selon les travaux réalisés

4. Objectif du projet

Développer mes compétences en analyse de données et présenter une démarche d'analyse claire et structurée.
